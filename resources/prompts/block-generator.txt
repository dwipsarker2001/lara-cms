TEMPLATE VARIABLE & LOGIC SYNTAX:
The CMS supports flat replacements, direct loops, list index references, newline splitting, and conditionals:

1. Flat / Object Variable:
   {{ fieldName }}
   {{ objectName.subField }}

2. Explicit Index Reference (useful for fixed grids):
   Format: {{ listName.0.fieldName }}, {{ listName.1.fieldName }}
   Example: {{ reviews.0.name }}

3. Conditionals ({% if ... %} ... {% endif %}):
   Works with string evaluations, booleans, or checks:
   {% if showBadge == 'true' %}<span class="badge">New</span>{% endif %}
   {% if plans.0.featured == 'true' %}<span class="popular">Popular</span>{% endif %}

4. Loops ({% for item in list %} ... {% endfor %}):
   Works on lists or splitting multiline strings by newlines:
   - Object list loop:
     {% for card in cards %}
       <div data-list="cards" class="group flex flex-col overflow-hidden rounded-2xl border border-gray-100 bg-white shadow-sm transition-transform duration-300 hover:-translate-y-1">
         <div data-edit="image" class="relative h-52 overflow-hidden rounded-t-2xl bg-gray-100">
           <img src="{{ card.image }}" class="h-full w-full object-cover" />
         </div>
         <div class="p-5">
           <h3 data-edit="title" class="text-lg font-semibold text-gray-900">{{ card.title }}</h3>
           <p data-edit="description" class="mt-2 text-sm text-gray-500">{{ card.description }}</p>
         </div>
       </div>
     {% endfor %}
   - Splitting string by newlines (split):
     {% for feature in plan.features.split('\n') %}
       <li>{{ feature }}</li>
     {% endfor %}

   IMPORTANT: For list loops, always give each repeated item a clear card-like structure and make the visible fields editable with data-edit attributes.

JSON ESCAPING RULES (CRITICAL FOR PARSING):
To prevent JSON parsing errors, follow these rules strictly inside the "template" string:
1. Double Quotes: Escape all double quotes inside the template as `\"`.
   Example: `<div class=\"my-card\">`
2. DO NOT Escape Single Quotes: Single quotes must NOT be escaped. Do NOT write `\'`.
   Example: Correct: `url('https://...')` | Incorrect: `url(\'https://...\')`
3. Escaped Newlines: Do NOT include raw/real newlines in the string value. Use the literal character sequence `\n` to break lines.
4. Backslashes: Only use backslashes for `\"` and `\n`. Avoid other escapes like `\s`, `\d`, or `\w`.
